## 🚀 起動方法・更新方法

### 【一番かんたんな起動方法】
フォルダ内にある **`index.html`** をダブルクリックするだけで、お使いのブラウザ（Google Chrome, Edge, Safari等）ですぐに起動して閲覧できます！

### 【GitHubへの自動アップロード（ワンクリック更新）】
フォルダ内にある **`deploy.bat`** をダブルクリックするだけで、更新したファイルをすべて自動でGitHubへアップロード（プッシュ）できます！
- 初回起動時のみ：GitHubリポジトリのURL（例: `https://github.com/kaki-palette/xxx.git`）の入力を求められます。一度入力すれば次回以降は完全自動でアップロードされます。

### 【手動でGitHubへアップロードする場合の対象ファイル】
GitHub（GitHub Pages等）にアップロードが必要なファイルは以下の3点（＋説明書）だけです：
- **`index.html`**（メインホームページ）
- **`calendar.html`**（推し活カレンダー専用ポスターページ）
- **`assets/`** フォルダ（ロゴ画像が入っています）
- **`README.md`**（本説明書）
