# 🎾 テニプリ部 (新テニスの王子様 Fan Portal & Archive)

『テニスの王子様』『新テニスの王子様』の公式最新ニュース、アベイル等のグッズコラボ、アニメ、テニミュ、キャラクター誕生日を完全網羅したファン向けオタ活ポータルサイトです。

---

## 🚀 起動方法

### 【一番かんたんな起動方法】
フォルダ内にある **`index.html`** をダブルクリックするだけで、お使いのブラウザ（Google Chrome, Edge, Safari等）ですぐに起動して閲覧できます！

### 【スマホ・友達に公開する場合】
このフォルダの中身をそのまま [GitHub Pages](https://pages.github.com/) にアップロードするだけで、完全無料（0円）で誰でもスマホから見れるようになります。

---

## 📁 フォルダ構成

- **`index.html`** : **【メイン起動ファイル】** ダブルクリックで開くファイルはこれ1つだけです。
- **`quiz_data.json`** : 「新テニプリ ネタクイズラリー」のマスター問題データ（全30問）
- **`過去の作成データ_バックアップ/`** : 過去に作成・検証したHTMLや作業用スクリプトの保管フォルダ
- **`過去の開発環境_Vite_React/`** : 初期のReact/Vite開発用ファイル（src, public等）の保管フォルダ

1. **新テニプリ 公式ナレッジ4択クイズラリー**：
   - テニプリガチ勢ファンも唸る、原作コミックス・公式ファンブックの完全正史に基づく本格4択クイズ（全30問）。
   - 全国大会決勝（手塚vs真田の「陰」と「雷」、不二vs仁王の「心の瞳」と「星花火」、大石・菊丸vs丸井・ジャッカルのD1など）や、名勝負のスコア（手塚vs跡部の「35-37」、不二唯一の敗北・白石戦「6-7」）、馬上テニス、純金ガントレットなど名シーンを完全網羅！
